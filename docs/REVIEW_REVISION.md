## Geometry

Native sensor centers have integer `(x,y)` coordinates, x right, y down. `frame(x,y)=reference(x+dx,y+dy)` defines translation sign. `Geometry.forward[B,K,H,W,2]` maps frame centers to reference centers in native pixels. `Geometry.inverse` maps reference centers to frame centers and is computed by numerically inverting the entire homography-plus-polynomial mapping. Frame zero is identity. v1 splats forward centers to `((x_ref+.5)*scale-.5,(y_ref+.5)*scale-.5)` and excludes out-of-grid contributors. Counts describe support; unsupported colors use the documented per-color fallback.

The Transformer evaluates inverse maps at each CFA reference center `(2*x+cx,2*y+cy)` and converts source coordinates to that same-color plane `(source-cfa_offset)/2`. Bilinear weights are squared for variance; masks require all contributing samples to be valid, and outside support is invalid. Exposure normalization remains in reference-frame-zero units. No forward map is reused as an inverse sampling grid.

`estimate_geometry` uses green-cell averages resized to native coordinates, percentile-normalized for feature matching. GFTT local controls and pyramidal LK produce reference-to-frame tracks. Reverse LK checks use a .75 native-pixel threshold. Actual frame-to-frame LK tracks must agree with reference-origin tracks within 1 native pixel for every other frame. These checks affect which controls are fitted. RANSAC homography uses a 1-pixel threshold. Polynomial monomials use x/y normalized to [-1,1], total degree <=4. Fits need twice as many controls as terms and condition number <=1e5. Degree descends deterministically; insufficient controls retain homography only. Singular/ill-conditioned homographies, nonfinite maps or failed inverse convergence fall back to identity with an explicit reason. Confidence is surviving local controls / detected reference controls, a heuristic fraction rather than calibrated probability. Degree fallback, control count, cross-frame error, homography, fit RMS and inverse error are reported. Low-texture inputs receive identity fallback. Alignment does not read fixture shifts.

Both inference CLIs accept `--alignment robust`; existing `estimated` phase-correlation translations and `provided` shifts retain their old meanings. Model APIs accept an explicit Geometry object; training preprocessing can pass the same object without changing the backbone.

## Shared LCA and amplitude

`JSRModel(lca_offsets_native=[[dxR,dyR],[dxG,dyG],[dxB,dyB]])` configures channel observation offsets: observed channel(x,y) measures ideal(x+dx,y+dy). Correction samples observed at `(x-dx*scale,y-dy*scale)` on the output grid. Both learned and legacy branches use identical bilinear geometry and border replication before RefineNet. `None` is exact identity. No lens estimation is implied.

Controller feature completion/canonicalization uses **initial legacy** amplitude. RefineNet's amplitude is recomputed from **transformed legacy** after both branch transforms. Normalization ablation retains constant reference amplitude in RefineNet. `diagnostics=True` exposes initial legacy, pre-LCA learned, Controller amplitude and RefineNet amplitude; default output keys remain rgb/legacy/learned. LCA is linear and amplitude is positively homogeneous; corrected sign and both amplitude locations are tested.

## Capture order

`capture_order[B,7]` is the temporal rank of each stored frame, a permutation of 0..6 independent of EV. Reference frame remains stored at index zero; its capture rank need not be zero. `capture_order_mode: explicit-ranks-v1` sorts per-frame features by those ranks before temporal differences and late pair fusion. Storage permutations preserving reference zero and corresponding metadata leave the result invariant. Invalid ranks or absent required ranks are rejected. Checkpoint model config includes the mode and existing exact-resume config comparison guards changes.

Old model configs default to `legacy-storage-v1`, preserving storage-index temporal semantics even if new metadata exists. Missing archive order is reported as `missing: legacy storage order`. No EV sorting or silent checkpoint reinterpretation occurs. Optional `data.options.capture_order` is carried by both datasets, batching, NPZ save/load. The example explicit config's ranks are independently chosen synthetic metadata, not a claimed author's capture schedule.
