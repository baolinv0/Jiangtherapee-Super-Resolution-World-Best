# Sensor/PTC research for JSR

Retrieved 2026-10-05 by verified HTTPS. Research files only; no repository source, packages, branches, or configuration changed. Primary-source fetch status, content sizes, and SHA-256 hashes are recorded in `fetch-log.json` and `assets/fetch*.json`. Downloaded ELD `.npy` and PMN `.pkl` objects were inspected with NumPy header readers / `pickletools`, never unpickled or executed. Large RAW datasets and large calibration maps were not downloaded.

## Decision

A practical independent prototype can replace the generic analytic profile with **published fitted noise parameters for one explicitly named donor full-frame camera**, then acquire target-body RAW flats/darks to build a defensible measured library. PMN supplies explicit SonyA7S2 coefficients throughout ISO100–800; ELD supplies additional Canon5D4/NikonD850/SonyA7S2 fitted distributions. Neither is the JSR author's library; neither establishes calibration across all full-frame cameras, all sensor pitches, or all readout modes. Combining a donor camera's noise with a different camera's spectral curves/pitch is an inferred hybrid, not a measured camera profile.

## 1. EMVA 1288: method and obtainable reference tests

Primary verified sources, all HTTP200:

- [EMVA1288/emva1288 reference implementation README](https://raw.githubusercontent.com/EMVA1288/emva1288/2ed0b403e299b1a56c4a0a392f99d1ac2f2c1b8e/README.rst). Explicitly calls itself the reference implementation for *Standard for Measurement and Presentation of Specifications for Machine Vision Sensors and Cameras*, mapping current master/software1.x to standard4.0. This is a measurement method/software, not a consumer full-frame PTC library. The standard4.0 release year was not independently verified from the blocked official PDF.
- [Pinned Results1288 implementation](https://raw.githubusercontent.com/EMVA1288/emva1288/2ed0b403e299b1a56c4a0a392f99d1ac2f2c1b8e/src/emva1288/process/results.py): overall system gain `K` is slope of dark-subtracted temporal variance vs dark-subtracted mean, unit DN/electron; `1/K` is e/DN. QE is responsivity divided by K and requires incident-photon calibration. Includes temporal dark noise, saturation capacity, PRNU, DSNU and row/column components. Gain sensitivity fit extends to70% of measured saturation; linearity evaluation uses5–95%. The JSR fitter's5–70% interval is a reasonable limited approximation, not proof of EMVA conformity. Quantization/dark-noise rules in the full implementation are more detailed than the JSR fit.
- [Pinned tutorial](https://raw.githubusercontent.com/EMVA1288/emva1288/2ed0b403e299b1a56c4a0a392f99d1ac2f2c1b8e/doc/tutorial.rst) links the standard development group's example datasets and makes clear the included simulator generates synthetic images.
- [Official example dataset repository](https://github.com/EMVA1288/datasets), HTTP200. Three sets: CCD12-bit, CMOS8-bit, simulation12-bit. The [CCD descriptor](https://raw.githubusercontent.com/EMVA1288/datasets/master/EMVA1288_ReferenceSet_001_CCD_12Bit/EMVA1288_Data.txt) identifies Basler AG,2011,640x480, standard3.0; the [CMOS descriptor](https://raw.githubusercontent.com/EMVA1288/datasets/master/EMVA1288_ReferenceSet_002_CMOS_08Bit/EMVA1288_Data.txt) identifies STEMMER IMAGING,2011,2048x512, standard3.0. These contain exposure/photon metadata, flat pairs and spatial bright/dark stacks. Sample actual PNG endpoints returned HEAD200 with lengths205249B(CCD),332198B/332241B(CMOS paired flats). No images downloaded. Data descriptors license CC BY-SA3.0. This offers non-synthetic input for calibration-tool regression, but these are machine-vision test sets with no consumer-camera ISO100–800 mapping and no full-frame/Bayer coverage.

Blocked official endpoints: `https://www.emva.org/standards-technology/emva-1288/` and `https://www.emva.org/wp-content/uploads/EMVA1288-4.0Linear.pdf` both returned proxy CONNECT403. No PDF-based claims are made.

## 2. ELD: published fitted parameters and extreme-low-light evaluation RAWs

Paper: *A Physics-based Noise Formation Model for Extreme Low-light Raw Denoising*, Wei et al., CVPR2020; journal version *Physics-based Noise Modeling for Extreme Low-light Photography*, accepted2021 (TPAMI44(11),8520–8537, per official README).

Primary verified sources, all HTTP200:

- [Pinned official README](https://raw.githubusercontent.com/Vandermode/ELD/53d5408dec3a33e5ca304bb49682d7b6b6dc79c2/README.md): ELD evaluation dataset uses ISO800,1600,3200, illumination ratios1/10/100/200. Evaluation dataset is not a dedicated RAW flat/dark PTC sweep. January2022 release includes calibrated camera noise parameters and baseline G/G+P/G+P* models; original full noise model/calibration code remains described as restricted by business license. Software LICENSE fetched is MIT; external dataset's independent license/access was not verified.
- [Pinned official noise.py](https://raw.githubusercontent.com/Vandermode/ELD/53d5408dec3a33e5ca304bb49682d7b6b6dc79c2/noise.py): supported camera names are CanonEOS5D4,CanonEOS70D,CanonEOS700D,NikonD850,SonyA7S2. The5D4,D850,A7S2 are the full-frame candidates;70D/700D are APS-C. This is camera-specific fitted-distribution support, not coverage of other models/bodies.
- [Pinned RAW loader](https://raw.githubusercontent.com/Vandermode/ELD/53d5408dec3a33e5ca304bb49682d7b6b6dc79c2/dataset/sid_dataset.py): reads per-channel RAW black levels and exposure/ISO metadata. Do not transfer its white/black normalization to a different body.
- Actual small calibrated parameter files were retrieved for [Canon5D4](https://raw.githubusercontent.com/Vandermode/ELD/master/camera_params/release/CanonEOS5D4_params.npy), [NikonD850](https://raw.githubusercontent.com/Vandermode/ELD/master/camera_params/release/NikonD850_params.npy), [SonyA7S2](https://raw.githubusercontent.com/Vandermode/ELD/master/camera_params/release/SonyA7S2_params.npy), and the two APS-C bodies. Sizes1758,2156,1807,1696,1703B respectively. Headers/pickle bytecode show `Kmin,Kmax,G_shape,color_bias,Profile-1{g_scale,G_scale,R_scale}`;D850 also `Profile-2`. There are no ISO-indexed coefficient keys in these released dictionaries.

`noise.py` Poisson synthesis `Poisson(y/K)*K` establishes K=DN/e; Gaussian scale is DN. Its current code deliberately samples logK over0.1..30 (stored Kmin/Kmax sampling is commented), uses ratio100..300 and hardcoded saturation_level16383−800. It does not implement a discrete measured ISO100/200/400/800 PTC map or supply full-well measurements. Thus it can supply donor noise-distribution priors, but an ISO lookup, physical clipping, channel transmission and target-body validation must be established separately.

The official README's GoogleDrive/Baidu dataset links were not followed for download or access verification. CVF official paper URL and arXiv2108.02158 both returned proxy CONNECT403. The project's README/code, not an unseen paper, substantiates the findings above.

## 5. Distinctions that affect implementation

- **Spectral sensitivity vs PTC:** wavelength-indexed R/G/B response tells how incident spectra produce relative channel signals. PTC tells temporal variance vs mean and electron-to-DN conversion. One does not substitute for the other. Normalized spectral curves do not establish absolute QE/full-well/read noise; broadband RGB gain ratios do not recover spectral curves. If a response curve already includes CFA throughput/QE, multiplying another transmission term must be a clearly specified factor rather than counting the filter twice.
- **Shared PTC vs transmission:** shared electronic K/read/full-well across CFA colors is compatible with different photons collected under R/G/B filters. Apply spectral/channel photon throughput before Poisson/electron capture; calibrate/check electronic slopes on R,G1,G2,B separately, and pool only when shared law is supported. Transmission remains tied to wavelength/illuminant/response normalization, not an arbitrary color-noise correction. Test both electronic and photon assumptions.
- **Full-well vs ADC saturation:** `white_dn` is a digital/RAW clipping boundary; it is not a measured physical electron full-well. For e/DN gain g, ADC headroom is g*(white_dn−black_dn); usable electron ceiling is approximately min(full_well_e,ADC_headroom_e). ADC may clip before full-well at high ISO. Linear PTC gain fitting only yields g/read noise; linear-region data do not identify physical full-well. Near-saturation sweeps/nonlinearity and readout-mode constraints are needed; when only ADC clips, record FWC as unknown/lower-bounded, not equal to ADC headroom.
- **ISO points vs interpolation:** source entries are fitted coefficients; actual target-body measured points require capture metadata/RAW hashes and fit diagnostics. In-between values can be piecewise fitted/interpolated only inside a verified gain/readout mode, marked inferred, tested at withheld ISO values. Do not enforce g∝1/ISO or smooth read noise through a conversion-gain switch solely from ISO labels. For initial discrete training, use verified100/200/400/800 anchors; use source's named intermediate entries as donor coefficients with their own provenance, not target measurements.

## 6. Practical target-body capture and model

1. Start with one named full-frame body + firmware + RAW bit depth/readout/compression mode + temperature range. Capture ISO100,200,400,800 first; add125,160,250,320,500,640 if “100–800” means all selectable values. Record body identifier, black/white levels, optical setup and file checksums. Avoid binding each spectral curve/pitch sample to this body without measured correspondence.
2. Use a stable flicker-free integrating-sphere/diffused uniform flat. For each ISO collect about20 illumination levels with4–8 repeated RAW frames per level, plus64 shortest-exposure dark frames and representative longer dark exposures at matched temperature/readout. Cover linear5–70% headroom for gain, add low-signal points, and independently sweep near/above saturation to find nonlinearity/clip type. No white balance, denoising, tone curve, demosaic or lossy RAW; verify firmware cannot silently apply relevant correction. If varying exposure rather than illumination, account for exposure-dependent dark current.
3. Compute each CFA-plane dark-subtracted mean μ_DN and temporal paired-flat variance Var(flat1−flat2)/2, excluding defective pixels, border/optical black and clipped samples. Fit v_DN²=K_DN/e*μ_DN+v_dark, with measured dark variance and uncertainty from independent pairs/ROIs. Infer g_e/DN=1/K. After applicable ADC variance correction, Gaussian read_e=g*sqrt(max(v_dark−v_ADC,0)). Preserve fixed dark mean/DSNU separately from temporal residual banks; preserve row/column covariance if observed. The repository currently strips per-pixel temporal mean in residual banks, so these banks do not supply DSNU.
4. Shared-slope RGB validation should precede one scalar PTC. Fit R,G1,G2,B on matched exposure series and compare confidence intervals/residuals; if they differ because of electronic or RAW processing behavior, record per-plane law or label shared law as an approximation. Relative photon transmission needs a specified illuminant/normalized spectral response; absolute QE needs calibrated irradiance/photon count. Do not infer it from generic default[.70,1,.55].
5. Export existing flat_pairs[L,2,H,W]/dark[T,H,W] manifest for `calibrate_stacks.py` as a first implementation path, while separately reporting FWC/transmission sources. Current schema requires FWC/transmission input and supports one scalar Gaussian gain/read law; it cannot represent unknown FWC, dual-mode metadata, heavy-tail/row/DSNU/PRNU components or per-field measured-vs-inferred provenance without an explicit later extension. Reduced donor profiles must remain labelled approximations until those gaps are handled.

## 7. Calibration and partial-saturation validation

Use held-out exposures/ROIs/capture runs, not the flat levels used for fitting. Compare predicted and measured DN mean/variance curves, low-signal histograms/tails, dark row/column spectra and spatial covariance, PRNU/DSNU, and near-saturation onset/flattening. Report residuals and confidence intervals perISO/CFA/mode. A lossless finite-gradient training smoke is not this validation. Reference EMVA real sets can exercise method, while same-body withheld captures establish applicability.

For JSR, build observed-data evaluation strata: no channels clipped; exactly one channel clipped; two channels clipped; all channels clipped; and whether any shorter burst exposure still sees the clipped channel. Use RAW measured clipping masks for observations; unclipped clean reference/HDR target only for ground truth. Hold out camera/body/calibration sessions and spectral/material scenes. Evaluate unclipped-channel color error and reconstruction error specifically on partially saturated masks versus corrected merge and other baselines. Cross-channel recovery is statistically learned, not uniquely determined from arbitrary spectra; all-channel/all-exposure saturation lacks observed radiometric evidence. Demonstrate improvement under these masks after real training before claiming recovered partial saturation.
